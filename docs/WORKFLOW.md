# YardWise Team Workflow

This file tracks each team member's contributions during each sprint.

## Contribution Tracking

Every team member must complete at least one piece of accepted work per sprint.

Work is accepted when it meets the task requirements and the team's Definition of Done.

- **Code:** Completed, checked, and merged into `main`.
- **Other work:** Completed, reviewed, and documented.

## How to Record Contributions

Each team member adds a row for their work. Include their name, what they completed, a GitHub Issue or Pull Request link (or other evidence), and the status.

Use `In Progress` or `Accepted` for status. Only accepted work counts toward the sprint requirement.

For paired work, each person should record their specific contribution.
