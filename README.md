# YardWise

YardWise is a landscaping and gardening app that helps homeowners and renters plan, organize, and maintain outdoor projects.

## Features

- Manage properties and outdoor projects
- Search and view plant information
- Receive plant recommendations
- Create project tasks
- Track project materials and budgets
- Upload yard and project photos
- Schedule maintenance reminders
- Store gardening notes and project information

## Setup

### Mobile
- React Native
- Expo
- TypeScript

### Backend
- FastAPI
- Python
- REST API

### Database & Authentication
